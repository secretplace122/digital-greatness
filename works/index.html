Лендинг для массажной студии. Сайт включает информацию об услугах, карту проезда, контактные данные для клиентов, виджет из Яндекс-бизнес с оценкой организации на Яндекс картах, а также адаптивный дизайн для удобного просмотра с любых устройств. Лендинг Февраль 2025

Студия по наращиванию ресниц "Ilonalashbar"

Одностраничный лендинг для студии наращивания ресниц с фиксированной навигацией по якорям. Реализованы: секция с фоновым изображением и информацией о мастере, блок обучения с табами выбора курса (индивидуальный/групповой), прайс-лист с тремя ценовыми категориями, горизонтальная галерея с автопрокруткой, блок отзывов и контактов. В топе поисковой выдачи Яндекса . Добавлена метрика Яндекс, модальные окна для курсов. Отличные показатели в метриках .
